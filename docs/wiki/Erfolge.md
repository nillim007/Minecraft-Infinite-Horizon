# Erfolge

Die Erfolge von Infinite Horizon stehen im Erfolgsmenü (Taste `L`) auf einem eigenen Reiter. Sie zeichnen die Reise vom ersten Forschungsterminal bis zum Start des Sternenschiffs nach.

| Erfolg | So bekommst du ihn |
| --- | --- |
| Infinite Horizon | Nimm das [Ingenieurs-Handbuch](Willkommen-bei-Infinite-Horizon.md) in die Hand. |
| Bodenstation | Setz ein [Forschungsterminal](Forschung.md). |
| Erstes Signal | Eine Sonde deiner Agentur erreicht den Mond. |
| Ein kleiner Schritt | Betritt den Mond. |
| Rote Erde | Betritt den Mars. |
| Drei Minuten Hölle | Steig auf der Venus unter die Wolkenschicht (unter y 180) und kehre wieder hinauf zurück. |
| Eigene Luft | Ein Kuppelgenerator deiner Agentur läuft zum ersten Mal. |
| Zuhause im Orbit | Setz einen [Stationskern](Die-Raumstation.md). |
| Sonne in der Flasche | Ein [[fusionsreaktor | Fusionsreaktor]] deiner Agentur erzeugt Strom. |
| Unter dem Eis | Tauch auf Europa unter die Eisdecke ins Wasser. |
| Am Rand | Betritt Pluto. |
| Der Sender | Besiege den Wächter am Sender. |
| Netzwerk | 5 Routen deiner Agentur sind gleichzeitig aktiv: Jede hat mindestens eine Rakete, und keine davon meldet „ohne Treibstoff“. |
| Infinite Horizon (Sternenschiff) | Starte das Sternenschiff an der [[werft | Orbitalwerft]]. |

## Für die ganze Agentur

Erfolge, die eine Maschine oder ein Ereignis auslöst, bekommen **alle Mitglieder** deiner Agentur: Erstes Signal, Eigene Luft, Sonne in der Flasche, Netzwerk und das Sternenschiff. Wer gerade nicht online ist, bekommt sie beim nächsten Betreten der Welt.

Beim Start des Sternenschiffs bekommen auch alle [Partner](Deine-Agentur.md)-Agenturen den Erfolg, die etwas an die Werft geliefert haben.

> [!TIP]
> Der Server schreibt jeden Erfolg mit Uhrzeit und Spielername in die Datei `logs/infinite_horizon-progress.log`. Sie bleibt auf dem Server und wird nirgendwohin geschickt.
