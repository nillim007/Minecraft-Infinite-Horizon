---
title: Upgrades
---
Every machine has two upgrade slots at the bottom right. Generators and storage blocks have none.

- **Slot 1:** <item:infinite_horizon:speed_upgrade> – each operation takes only {{value:machines:speed_upgrade.ticks_multiplier}} times as long, but uses {{value:machines:speed_upgrade.energy_per_tick_multiplier}} times the power per tick.
- **Slot 2:** <item:infinite_horizon:efficiency_upgrade> – lowers power use per tick to {{value:machines:efficiency_upgrade.energy_per_tick_multiplier}} times.

Each slot takes up to {{value:machines:speed_upgrade.max_stack}} upgrades. The effects multiply: four speed upgrades make a crusher more than three times as fast.

@recipes_for infinite_horizon:speed_upgrade infinite_horizon:efficiency_upgrade

@tip Combine both: speed upgrades for more pace, efficiency upgrades so your cable network does not get overloaded.

@note You can insert and remove upgrades at any time. A running operation keeps its progress.
